# Макеты

Экспорт согласованного концепта. Файлы — HTML-разметка с примерными данными (рантайм дизайн-редактора не включён, поэтому в браузере они не отрисуются как есть).
Используй их как референс структуры, отступов, текстов и статусов; цвета и шрифты — в docs/DESIGN.md.

- Main.dc.html — «Сегодня», десктоп
- Library.dc.html — конспекты
- Topics.dc.html — темы и очередь сдачи
- Mobile.dc.html — телефон студента (390×844)
- Starosta.dc.html — форма изменения расписания для старосты (390×844)
