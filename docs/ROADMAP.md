# План реализации

Работать по одному этапу. В конце каждого: lint, typecheck, тесты, короткий отчёт «что сделано / что проверить руками», коммит.

## M0 — Каркас
- Next.js 15 + TS strict + Tailwind v4 + ESLint/Prettier, pnpm
- `docker-compose.yml`: postgres 16, minio (+ создание бакета)
- Drizzle: схема по `docs/schema.sql`, первая миграция
- Токены и шрифты из DESIGN.md, базовый layout с `TopNav` / `BottomTabBar`
- `.env.example`, `README.md` с запуском за 3 команды
- Seed: семестр «Осень 2026», сетка звонков, 5 дисциплин и недельное расписание из макетов
- **Готово, когда:** `docker compose up -d && pnpm db:migrate && pnpm db:seed && pnpm dev` показывает пустой каркас с навигацией.

## M1 — Вход и роли
- Telegram Login Widget, проверка hash, сессия в cookie
- Инвайты: `/join/<code>`, экран «нет доступа»
- Guards `requireMember`, `requireRole('starosta')`
- Dev-вход без Telegram только при `NODE_ENV=development` (выбор тестового пользователя)
- **Готово, когда:** вход через тестового бота работает на домене/туннеле, роли проверяются на сервере, есть тесты проверки hash.

## M2 — Расписание (ядро)
- `lib/schedule/resolve.ts` + все тесты из DATA_MODEL.md (сначала тесты)
- Экран «Сегодня» и «Неделя» по макету Main/Mobile
- Панель старосты: форма изменения (отмена/замена/перенос/доп./аудитория) по макету Starosta, история и отзыв изменения
- Редактор базового расписания (можно простую таблицу на первом шаге)
- **Готово, когда:** староста с телефона вносит перенос, у студентов он сразу виден на обоих днях.

## M3 — Новости и Telegram-бот
- Лента новостей, публикация, закреп
- grammY-бот: отправка изменений/новостей в чат группы (`TELEGRAM_GROUP_CHAT_ID`), ссылки на сайт; команды `/today`, `/week`
- Очередь отправки с повторами (простая таблица `outbox` + воркер в процессе бота)

## M4 — Темы
- Списки тем, взятие/освобождение (атомарно), очередь сдачи
- Инструменты старосты: вставка тем списком, назначение дат, «сдано»
- Напоминание о дедлайне в Telegram

## M5 — Рубежки
- CRUD, список, отсчёт «через N дней», метка в расписании дня

## M6 — Конспекты
- Загрузка (multipart → server, sharp: EXIF strip, 2560/480 webp), файлы PDF/DOCX/PPTX
- Библиотека по макету Library, lightbox, фильтры, поиск по теме занятия
- Подписанные URL, лимиты и rate limit

## M7 — PWA и календарь
- Манифест, иконки, service worker с кэшем расписания на неделю
- Персональный iCal-фид
- (опционально) web push об изменениях

## M8 — Деплой
- Dockerfile (standalone output), compose для прод, Caddy с HTTPS
- Бэкапы: `pg_dump` + `mc mirror` по cron, хранение 14 дней
- Мониторинг: healthcheck-эндпоинт, логи
