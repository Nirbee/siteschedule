# Дизайн-система «пара.»

Согласованные макеты: `design/` (Main — сегодня, Library — конспекты, Topics — темы, Mobile — телефон студента, Starosta — форма старосты). Разметку смотреть как референс отступов, размеров и иерархии; реализовать заново на Tailwind-компонентах.

## Характер
Спокойный «бумажный» фон, белые карточки с тонкой рамкой, чёрные акцентные блоки для самого важного (сегодняшний день, рубежки). Никаких градиентов, теней-подложек, эмодзи. Изменения расписания должны бросаться в глаза, всё остальное — тихое.

### Статусы расписания (текст / фон)
| Статус | Текст | Фон | Подпись |
|---|---|---|---|
| Отмена | `#A53A12` | `#FBE6DC` | «Отменена» + зачёркнутое название `#7D828C` |
| Замена / смена аудитории | `#1F43C4` | `#E4E9FC` | «Замена», «Аудитория изменена» |
| Перенос | `#5E3391` | `#EFE7F8` | «Перенесена на …», «Перенос с …» |
| Доп. пара | `#0F6B4D` | `#DDF1E7` | «Доп. пара» |

Статус никогда не передаётся только цветом — всегда есть текстовая подпись.

Тёмная тема — в бэклоге; токены заводить через CSS-переменные сразу, чтобы потом добавить.

## Типографика
- Заголовки и логотип: **Unbounded** 700 (h1 34–40px, letter-spacing −0.03em; h2 17–20px)
- Текст: **Manrope** 400/500/600/700, база 15–16px, line-height 1.45–1.5
- Время, даты, номера: **JetBrains Mono** 500/600 (табличные цифры)
- Подключать через `next/font/google` с `subsets: ['latin', 'cyrillic']`.
- Надзаголовки-«оверлайны»: JetBrains Mono 12–13px, uppercase, letter-spacing 0.08em, цвет `muted`.

## Форма и отступы
- Радиусы: карточки 16px, кнопки и поля 10–12px, бейджи 6–8px, чипы-фильтры 999px.
- Карточка пары: padding 22px (телефон 14px), gap 20px. Между карточками 12px (телефон 8px).
- Контейнер: max-width 1280px, боковые отступы 24px (телефон 18px).
- Двухколоночные экраны: основная колонка `flex: 999 1 560px`, боковая `flex: 1 1 340px`, на узком экране боковая уходит вниз.
- Тач-цели ≥44px, высота полей формы 48px, главная кнопка формы 54px.

## Компоненты (минимальный набор)
- `TopNav` (десктоп) / `BottomTabBar` (телефон, 5 пунктов: Сегодня, Темы, Конспекты, Рубежки, Новости)
- `LessonCard` (все статусы из DATA_MODEL), `LessonCardCompact` (телефон)
- `WeekStrip` — 6 дней, текущий — тёмная плитка
- `StatusBadge`, `KindBadge`
- `StaffNote` — плашка комментария старосты с иконкой рупора
- `NewsItem`, `ExamItem` (тёмная карточка: дата моно + предмет + форма · «через N дней»)
- `TopicTable` + `QueueByDate`
- `MediaGrid` (3:4 превью, `auto-fill minmax(150px, 1fr)`), `Lightbox`, `FileRow`
- `UploadButton` / `UploadSheet`
- `SegmentedControl` (форма старосты), стандартные `Field`, `Select`, `Textarea`, `Checkbox`
- Иконки: `lucide-react`, stroke 1.8, 18–22px.
