# Дизайн-система «пара.»

Согласованные макеты: `design/` (Main — сегодня, Library — конспекты, Topics — темы, Mobile — телефон студента, Starosta — форма старосты). Разметку смотреть как референс отступов, размеров и иерархии; реализовать заново на Tailwind-компонентах. Макеты только светлые и с демо-данными; где макет расходится с SPEC.md (например, 3 типа изменений вместо 5), прав SPEC.md.

## Характер
Спокойный «бумажный» фон, карточки с тонкой рамкой, акцентные блоки для самого важного (сегодняшний день, рубежки). Никаких градиентов, теней-подложек, эмодзи. Изменения расписания должны бросаться в глаза, всё остальное — тихое.

## Темы
Светлая и тёмная с первого дня. По умолчанию — по `prefers-color-scheme`, в профиле можно выбрать «Системная / Светлая / Тёмная» (атрибут `data-theme` на `<html>`, ставится на сервере из `users.theme`, без мигания).

Все цвета — CSS-переменные, в компонентах только семантические токены (`bg-surface`, `text-muted`…), никаких hex. Tailwind v4: токены в `@theme`, значения переопределяются для тёмной темы.

### Статусы расписания (текст / фон)
| Статус | Светлая | Тёмная | Подпись |
|---|---|---|---|
| Отмена | `#A53A12` / `#FBE6DC` | `#FFA07E` / `#3A1F16` | «Отменена» + зачёркнутое название (`#7D828C` / `#7E8492`) |
| Замена / смена аудитории | `#1F43C4` / `#E4E9FC` | `#9DB1FF` / `#1D2648` | «Замена», «Аудитория изменена» |
| Перенос | `#5E3391` / `#EFE7F8` | `#CDAEF7` / `#2E2142` | «Перенесена на …», «Перенос с …» |
| Доп. пара | `#0F6B4D` / `#DDF1E7` | `#74D6AC` / `#12352A` | «Доп. пара» |
| Сдано (темы) | `#0F6B4D` / `#DDF1E7` | `#74D6AC` / `#12352A` | «Сдано» |

Контраст проверен (WCAG): основной текст и подписи статусов ≥ 5:1 в обеих темах; зачёркнутое название отменённой пары — 3.9:1 / 4.5:1 (крупный жирный текст, допустимо).

Статус никогда не передаётся только цветом — всегда есть текстовая подпись.

### Самостоятельная работа
Приглушённая карточка: фон `surface-muted`, без рамки-акцента, текст `muted`, без кнопок «Конспекты»/«Темы». В сводку «N пар» не входит.

## Типографика
- Заголовки и логотип: **Unbounded** 700 (h1 34–40px, letter-spacing −0.03em; h2 17–20px)
- Текст: **Manrope** 400/500/600/700, база 15–16px, line-height 1.45–1.5
- Время, даты, номера: **JetBrains Mono** 500/600 (табличные цифры)
- Подключать через `next/font/google` с `subsets: ['latin', 'cyrillic']` (шрифты самохостятся при сборке, к Google в рантайме не ходим).
- Надзаголовки-«оверлайны»: JetBrains Mono 12–13px, uppercase, letter-spacing 0.08em, цвет `muted`.

## Форма и отступы
- Радиусы: карточки 16px, кнопки и поля 10–12px, бейджи 6–8px, чипы-фильтры 999px.
- Карточка пары: padding 22px (телефон 14px), gap 20px. Между карточками 12px (телефон 8px).
- Контейнер: max-width 1280px, боковые отступы 24px (телефон 18px).
- Двухколоночные экраны: основная колонка `flex: 999 1 560px`, боковая `flex: 1 1 340px`, на узком экране боковая уходит вниз.
- Тач-цели ≥44px, высота полей формы 48px, главная кнопка формы 54px.

## Компоненты (минимальный набор)
- `TopNav` (десктоп) / `BottomTabBar` (телефон, 5 пунктов: Сегодня, Темы, Конспекты, Рубежки, Новости; неделя — из `WeekStrip`)
- `LessonCard` (все статусы из DATA_MODEL, пары не по сетке, самостоятельная), `LessonCardCompact` (телефон)
- `WeekStrip` — 6 дней, текущий — плитка `emph`; заголовок «6 неделя · знаменатель»
- `StatusBadge`, `KindBadge`
- `StaffNote` — плашка комментария старосты с иконкой рупора
- `NewsItem`, `ExamItem` (карточка `emph`: дата моно + предмет + форма · «через N дней»)
- `TopicTable` (места «1/2», участники) + `QueueByDate`
- `MediaGrid` (3:4 превью, `auto-fill minmax(150px, 1fr)`), `Lightbox`, `FileRow`
- `UploadButton` / `UploadSheet`
- `InboxGrid` — «Неразобранное»: мультивыбор, подсказка, «Отнести к…»
- `SegmentedControl` (форма старосты; 5 типов — две строки или горизонтальный скролл), `Field`, `Select`, `Textarea`, `Checkbox`, `TimePicker` (слот из сетки / «другое время»)
- `ThemeSwitch` (в профиле)
- Иконки: `lucide-react`, stroke 1.8, 18–22px.
