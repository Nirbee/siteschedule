# ТЗ: сайт группы «пара.»

## Цель
Одно место, где студент за 10 секунд узнаёт: какие пары сегодня и что изменилось, когда сдаёт свою тему, когда рубежка, где конспекты прошедшей пары и что написала староста. Сейчас это теряется в Telegram-чате.

## Роли
| Роль | Может |
|---|---|
| `student` | смотреть всё; брать/освобождать тему (до дедлайна); загружать фото и файлы к парам; удалять свои загрузки |
| `starosta` | всё, что student + вносить изменения в расписание, публиковать новости, редактировать базовое расписание, рубежки, списки тем, назначать даты сдачи, удалять любые загрузки |
| `admin` | всё + управление пользователями, ролями и инвайтами |

Вход — только через Telegram. Попасть в группу можно по инвайт-ссылке (код в URL), которую выдаёт староста/админ. Без инвайта после логина — экран «попросите ссылку у старосты».

## Разделы

### 1. Сегодня (главная)
- Заголовок: день недели, дата, чётность недели, сводка «N пар · X отмен · Y замен».
- Лента недели (Пн–Сб): число пар, бейдж изменения (перенос, отмена, доп. пара). Клик — открывает день.
- Карточки пар: номер, время начала/конца, тип (лекция/практика/семинар/лаба), предмет, аудитория, преподаватель.
  - Отмена: предмет зачёркнут, бейдж «Отменена».
  - Замена: бейдж «Замена», строка «вместо «…»», изменение аудитории «305 → 210».
  - Перенос: на исходный день — «Перенесена на сб, 10.10», на новый — «Перенос со ср, 07.10».
  - Комментарий старосты под парой.
  - Кнопки «Конспекты · N фото» и «Темы» (если у предмета есть список тем).
- Боковая колонка (на телефоне — ниже): последние 3 новости, ближайшие 3 рубежки с отсчётом «через N дней», «Твоя тема» (если есть).
- Если пар нет — пустое состояние «Пар нет» + ближайший учебный день.

### 2. Расписание (неделя)
- Сетка недели с навигацией вперёд/назад, те же статусы, что на «Сегодня».
- Экспорт в календарь: личный iCal-фид по секретной ссылке (`/ical/<token>.ics`), учитывает изменения.

### 3. Темы
- Выбор дисциплины → список тем: №, тема, кто выбрал, дата сдачи, статус (свободна / занята / твоя / сдано).
- «Взять тему» — атомарно (без гонок: уникальность в БД), одна тема на человека в списке. До дедлайна можно освободить.
- «Очередь сдачи» — группировка по датам.
- Староста: создаёт список (дисциплина, название, дедлайн выбора), добавляет темы (в т.ч. вставкой списка построчно), назначает даты, отмечает «сдано», может назначить тему вручную.

### 4. Рубежки
- Список рубежных контролей по датам: дисциплина, форма (письменная, тест, защита…), время/аудитория, условия допуска (текст).
- Староста — CRUD. Рубежки отображаются и в расписании дня как отдельная метка.

### 5. Конспекты
- Слева дисциплины с количеством материалов, справа занятия по датам (новые сверху): дата, тип и номер занятия, тема занятия, кто загрузил, сетка превью, прикреплённые файлы (PDF, DOCX, PPTX).
- Загрузка с телефона: выбрать пару (по умолчанию — текущая/последняя прошедшая), несколько фото за раз, необязательная тема занятия. Прогресс загрузки.
- Просмотр фото: полноэкранный, свайп между фото занятия, скачать оригинал.
- Фильтры: все / лекции / практики / файлы; поиск по теме занятия.

### 6. Новости
- Лента сообщений от старост: автор, время, текст (markdown без HTML), флаг «Важно» (закреп).
- При публикации — опция «Продублировать в Telegram-чат группы» (по умолчанию вкл).

### 7. Панель старосты (`/manage`)
- **Изменение расписания** (главный сценарий, должен занимать <30 секунд с телефона): тип (отмена / замена / перенос / доп. пара / смена аудитории) → выбор пары из ближайших 2 недель → поля по типу → комментарий → превью «Так увидят однокурсники» → «Опубликовать». Галочка «в Telegram».
- Редактор базового расписания семестра (сетка, чётность).
- Новости, рубежки, списки тем, инвайты.
- История изменений (кто, что, когда), отмена ошибочного изменения.

## Telegram-бот
- Публикует в чат группы: изменения расписания, новости, новые рубежки, напоминание о дедлайне выбора тем (за 1 день).
- Каждое сообщение со ссылкой на сайт.
- Ежедневная сводка в 08:00 МСК в личку тем, кто включил (опционально, этап позже).
- Команды: `/today`, `/week`, `/topics`.

## Нефункциональные требования
- Mobile-first, PWA (иконка на экран, офлайн-кэш расписания на неделю).
- Время везде по МСК.
- Быстро: главная < 1 с на 4G, без клиентского JS там, где не нужен.
- Безопасность: проверка подписи Telegram и срока `auth_date` (≤24 ч), httpOnly+Secure+SameSite cookie, CSRF через server actions, rate limit на загрузки и логин, приватные файлы отдаются только авторизованным (подписанные URL с коротким TTL), EXIF удаляется.
- Резервное копирование БД и бакета раз в сутки.
