# ТЗ: сайт группы «пара.»

## Цель
Одно место, где студент за 10 секунд узнаёт: какие пары сегодня и что изменилось, когда сдаёт свою тему, когда рубежка, где конспекты и материалы по предмету и что написала староста. Сейчас всё это теряется в Telegram-чате.

## Пользователи и группы
- МГТУ им. Баумана, кафедра ИУ8, магистратура. Сейчас две учебные группы: **ИУ8-11М** и **ИУ8-12М** (~20–30 человек каждая). Расписание у них общее, лекции и семинары проходят вместе.
- Система с самого начала поддерживает несколько групп: у каждой своё расписание, пара может быть общей для нескольких групп. В Telegram-чате есть и другие группы (например, 13М), их подключим позже, если захотят. Неподключённая группа видит экран «Ваша группа пока не подключена».
- Чётность недель: **числитель / знаменатель** (так в вузе). Неделя 1 семестра — числитель.

## Роли
| Роль | Может |
|---|---|
| `student` | смотреть всё; брать/освобождать тему (до дедлайна), вступать в командную тему; загружать фото и файлы к парам; удалять свои загрузки |
| `starosta` | всё, что student, плюс: изменения расписания, новости, базовое расписание, рубежки, списки тем, даты сдачи, разбор «Неразобранного», удаление любых загрузок |
| `admin` | всё, плюс пользователи, роли, группы, ссылки для входа |

Сейчас по одному старосте на группу и один админ. Права старосты действуют на все группы (расписание общее).

## Вход и доступ
- Вход только через Telegram-бота: «Войти» → открывается `t.me/<bot>?start=<код>` → пользователь жмёт Start → возвращается на сайт, и тот сам подхватывает вход (сайт опрашивает статус кода, код живёт 15 минут). Login Widget не используем.
- Telegram в РФ работает с VPN: пользователь входит с включённым VPN, дальше пользуется сайтом как угодно. Отдельный сценарий «переключения VPN» не делаем.
- **Сессия «навсегда»:** cookie на 400 дней, продлевается при каждом визите. Пользователя не должно выкидывать. Сессии хранятся в БД, админ может завершить любую.
- **Доступ:** при входе бот проверяет, состоит ли человек в Telegram-чате курса. Если да, доступ открыт и человек один раз выбирает свою группу из подключённых. Если нет — экран «Доступ только для участников чата группы». Админ может дать доступ вручную.
- **Второе устройство:** на новом устройстве «Войти по QR» → на залогиненном телефоне сканируем QR → подтверждаем. Telegram не нужен.
- **Ссылка для входа от админа** — запасной вариант, если у человека не получается войти через бота.
- iPhone: у PWA с экрана «Домой» свои cookie, поэтому в инструкции: сначала «На экран Домой», потом вход (или QR).

## Разделы

### 1. Сегодня (главная)
- Заголовок: день недели, дата, «6 неделя · знаменатель», сводка «N пар · X отмен · Y замен». Самостоятельная работа в «N пар» не входит.
- Лента недели (Пн–Сб): число пар, бейдж изменения (перенос, отмена, доп. пара). Клик открывает день.
- Карточки пар: номер, время начала/конца, тип (лекция / семинар / практика / лаба / самостоятельная работа), предмет, аудитория, преподаватель (если указан).
  - Отмена: предмет зачёркнут, бейдж «Отменена».
  - Замена: бейдж «Замена», строка «вместо «…»», изменение аудитории «305 → 210».
  - Перенос: на исходный день — «Перенесена на сб, 10.10», на новый — «Перенос со ср, 07.10».
  - Пара не по сетке звонков (перенос или доп. пара на «другое время») показывает своё время без номера пары.
  - Самостоятельная работа — приглушённая карточка без кнопок.
  - Комментарий старосты под парой.
  - Кнопки «Конспекты · N фото» и «Темы» (если у предмета есть список тем).
- Боковая колонка (на телефоне ниже): последние 3 новости, ближайшие 3 рубежки с отсчётом «через N дней», «Твоя тема» (если есть).
- Если пар нет — «Пар нет» и ближайший учебный день.

### 2. Расписание (неделя)
- Сетка недели с навигацией вперёд/назад, те же статусы, что на «Сегодня».
- Экспорт в календарь: личный iCal-фид по секретной ссылке (`/ical/<token>.ics`), учитывает изменения. Самостоятельная работа в фид не попадает.

### 3. Темы
- Выбор дисциплины → список тем: №, тема, кто выбрал, дата сдачи, статус (свободна / есть места / занята / твоя / сдано).
- У темы есть **вместимость**: 1 (по умолчанию), 2 или N человек (командные темы). «Взять тему» / «Присоединиться», пока есть места. Один человек — одна тема в списке. Всё атомарно, без гонок.
- До дедлайна выбора тему можно освободить (выйти из команды).
- «Очередь сдачи» — группировка по датам, внутри даты порядок выступления.
- Староста: создаёт список (дисциплина, название, дедлайн выбора, вместимость по умолчанию), добавляет темы (в т.ч. вставкой списка построчно), задаёт даты и порядок, отмечает «сдано», может вписать человека вручную.

### 4. Рубежки
- Список рубежных контролей по датам: дисциплина, форма (письменная, тест, защита…), время (пара по сетке или произвольное), аудитория, условия допуска.
- Староста — CRUD. Рубежки отображаются в расписании дня как метка.

### 5. Конспекты и материалы
По каждой дисциплине два раздела:
- **Занятия** — по датам (новые сверху): дата, тип и номер пары, тема занятия, кто загрузил, сетка превью, прикреплённые файлы.
- **Материалы** — файлы, не привязанные к конкретной паре: презентации преподавателей, методички, комментарии к лабам.

Функции:
- Загрузка с сайта: выбрать пару (по умолчанию текущая или последняя прошедшая) или «в материалы дисциплины», несколько фото за раз, необязательная тема занятия, прогресс загрузки.
- Файлы: фото (JPEG/PNG/HEIC/WebP, до 15 МБ) и документы (PDF, DOC/DOCX, PPT/PPTX, XLS/XLSX, TXT, ZIP/RAR/7Z, до 50 МБ). Аудио и видео не поддерживаем.
- Просмотр фото: полноэкранный, свайп внутри занятия, скачать.
- Фильтры: все / лекции / семинары / файлы; поиск по теме занятия и имени файла.

**Импорт из Telegram и автосортировка** (подробно в DATA_MODEL.md):
- Одноразовый импорт истории чата из экспорта Telegram Desktop (JSON + медиа).
- Дальше бот сам забирает новые фото и файлы из топиков «11М и 12М», General и «Важное». «Флуд» и топики чужих групп игнорирует.
- Автосортировка по времени сообщения (во время или сразу после пары → эта пара) и по тексту (сокращения предметов в подписи или имени файла: «ТСиСА», «ЗИС»…).
- Что не удалось разложить уверенно, попадает в **«Неразобранное»** с подсказкой. Разбирают только старосты и админ: выделить несколько → отнести к паре или в материалы. Есть отдельный список «Разложено автоматически» для выборочной проверки.

### 6. Новости
- Лента сообщений от старост: автор, время, текст (markdown без HTML), флаг «Важно» (закреп).
- При публикации — опция «Продублировать в Telegram-чат» (по умолчанию вкл).

### 7. Панель старосты (`/manage`)
- **Изменение расписания** (главный сценарий, должен занимать <30 секунд с телефона): тип (отмена / замена / перенос / доп. пара / аудитория) → выбор пары из ближайших 2 недель → поля по типу → комментарий → превью «Так увидят однокурсники» → «Опубликовать». Галочка «в Telegram».
  - Новое время (перенос, доп. пара): по умолчанию выбор пары из сетки звонков, опция «другое время» (начало и конец).
  - Затронутые группы: по умолчанию все группы этой пары, можно сузить (скрыто под «Дополнительно»).
  - Переносить можно на любой день, в т.ч. пт/сб/вс.
- Редактор базового расписания семестра (сетка, числитель/знаменатель, группы).
- «Неразобранное» и «Разложено автоматически».
- Новости, рубежки, списки тем.
- История изменений (кто, что, когда), отзыв ошибочного изменения.
- Админ: пользователи, роли, группы, ссылки для входа, сессии.

## Telegram-бот
- Отдельный процесс, может жить на другом сервере. **Доступа к БД не имеет**: общается с сайтом через внутренний API (`/api/bot/*`, подпись общим секретом). Telegram API вызывает только бот.
- Вход на сайт (`/start <код>`), проверка участия в чате.
- Публикация в чат курса (в топик «11М и 12М»): изменения расписания (сразу), новости, новые рубежки, напоминание о дедлайне выбора тем (за 1 день), сводка на завтра в 20:00 МСК.
- Личные уведомления по подписке: утренняя сводка в 07:30 МСК, напоминания за день о своей сдаче темы и о рубежке.
- Сбор фото и файлов из топиков чата (см. раздел 5).
- Каждое сообщение со ссылкой на сайт.
- Команды: `/today`, `/week`, `/topics`, `/settings` (подписки).

## Нефункциональные требования
- Mobile-first, PWA (иконка на экран, офлайн-кэш расписания на неделю).
- Светлая и тёмная тема с первого дня: по умолчанию по настройке системы, плюс ручной выбор в профиле.
- Время везде по МСК.
- Быстро: главная < 1 с на 4G, без клиентского JS там, где он не нужен.
- Безопасность: подпись запросов бота (HMAC + метка времени), httpOnly+Secure+SameSite cookie, CSRF через server actions, rate limit на загрузки и вход, файлы отдаются только авторизованным, EXIF (в т.ч. геолокация) удаляется.
- Репозиторий публичный: в нём нет реальных данных (расписание, люди, экспорты) и секретов. В seed только демо-данные.
- Резервное копирование БД и файлов раз в сутки, вне сервера.
- Задел под мобильное приложение: бизнес-логика в `lib/`, server actions — тонкая обёртка; сессии в БД позволят позже выдавать токены приложению.
